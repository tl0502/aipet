## 出口判断(M5 → RC)

### 必达项
- [ ] KPI 11.15-11.20 全部可观测(数据可拉)
- [ ] KPI 至少 3 项达标(根据 UAT v1.0 阈值)
- [ ] 杀死指标无命中(主动关心被举报率 / 装扮强制弹窗投诉 / token 月成本 P95 等)
- [ ] 灰度 W2 100 人 14 天 P0 事故 = 0
- [ ] 性能预算未超(常驻 ≤ 250MB / 安装包 ≤ 80MB)

### 可妥协项
- 边界 UAT 场景(RC 后修补)
- 装扮工坊小 polish(P1-R1)

## 关键风险

- r12 LLM 游戏 token 月成本(单次 2000 token 上限 + 设置可见消耗统计 + 告警)
- r13 自由活动被关(KPI 11.12 关闭率 > 15% → 默认关闭"逛桌面"子项)
