# ADR-010: 音效包来源

- **状态**: Accepted
- **决策日期**: 2026-05-01
- **Owner**: M0 决策周(产品 + 美术/音频)
- **Reviewers**: M0 决策周复审通过
- **目标完成**: M0 决策周内(W0)
- **影响范围**: P 声音表情(M4 实施)

## 背景

PRD v0.6 §7.16 + 架构 v0.3 §2.2 锁定:
- 本地音效包(诶嘿 / 嗯哼 / 咳 / 哎呀 / 喵 等),不调 TTS。
- MVP 内置 1 套基础音效包,12-20 条短音频(< 500ms / 条)。
- 总大小 ≤ 5MB。
- 用户可自定义包(P2)。

需要决定音频文件来源,涉及 IP 风险与质量控制。

## 备选方案

### 选项 A:**自录(产品配音)**

找 1-2 名声优录制 12-20 条短音效,我们 100% 拥有版权。

**优点**
- IP 风险零
- 风格可控(可以为不同人格录不同声线,虽然 MVP 都用 default)
- 可作为产品差异化(声音独特)

**缺点**
- 成本:每条专业声优录音 + 后期 ~¥200-500 → 12 条约 ¥3000-6000
- 时间:沟通+录制+后期约 1-2 周
- 需要准备录音棚 / 后期 / 文件格式标准化

### 选项 B:**采购授权(预制库)**

从 Audiojungle / Pond5 / Epidemic Sound 等平台购买"角色感叹/语气词"包。

**优点**
- 时间快(几天就能拿到)
- 质量有保证(专业制作)

**缺点**
- 成本:打包许可 ~¥500-2000(看授权范围)
- 不独占,其他产品可能用同款
- 需要审查授权细则(是否允许商用 / 是否允许重新分发)

### 选项 C:**CC0 资源拼凑**

从 Freesound / OpenGameArt / Mixkit 等 CC0 免费资源筛选。

**优点**
- 成本零
- 大多数 CC0 允许商用

**缺点**
- 质量参差不齐
- 风格难统一(每条来自不同作者)
- 仍需要人工审核每条音频的授权(CC0 也有些资源边界模糊)

### 选项 D:**AI 合成 + 后期**

用 ElevenLabs / suno 等生成简短语气词 + 后期处理。

**优点**
- 成本低
- 风格统一

**缺点**
- 商用授权需仔细看(各家政策不同,有些禁止生成内容直接商用)
- AI 生成的语气词可能"塑料感"重
- 法务对 AI 生成内容的版权归属仍在争议

## 我的倾向

**🌟 倾向选项 A 或选项 B**(优先 A,预算紧张时 B):

### 推荐 A 的理由
1. 产品差异化:独特音色是用户记忆点。
2. 长期价值:未来可在此基础上扩展不同人格的不同音效包。
3. 成本可控(¥3000-6000 一次性投入,远低于服务端运营成本)。

### 推荐 B 的理由(若 A 不可行)
1. 时间紧:M0 决策周内能搞定。
2. 质量稳:专业平台兜底。
3. 可在后续 P1-R1 内补 A(逐步替换)。

**不推荐 C/D**:
- C 风格不统一影响体验
- D 法务风险高(尤其是国内市场)

### 内置音效包内容建议

12-20 条覆盖:

| 触发场景 | voice_id | 内容(口语化) |
|---|---|---|
| 物理交互 - 头部 | `eheh` | 短促"诶嘿" |
| 物理交互 - 双击 | `surprised` | "诶?" |
| 拖拽抗议 | `protest` | "诶!" |
| 键鼠协同 | `come_on` | "嗯!"(加油) |
| 心情 happy | `happy_short` | 短笑 |
| 心情 sleepy | `yawn_short` | 打哈欠 |
| 心情 cozy | `relax_sigh` | 长舒 |
| 提醒触发 | `alert` | "嗯?" |
| 番茄完成 | `done` | "好~" |
| 接受庆祝 | `cheer` | "诶诶!" |
| 拒答 | `hmm` | "嗯…" |
| 通用感叹 | `mhm` | "嗯哼" |

(M0 决策时确认最终清单)

## 决策

**选定:选项 A — 自录(产品配音)**。

M0 内启动声优录制 12-20 条短音效(每条 < 500ms,OGG Vorbis 44.1kHz,bitrate ≤ 96kbps,总大小 ≤ 5MB),覆盖物理交互、心情变化、状态切换、提醒触达等场景。**预算 ¥3000-6000**(每条专业声优录音 + 后期 ≈ ¥200-500 × 12-20 条),100% 自有版权。

写入 `assets/voice_packs/default/` + `manifest.json`(每条音频含 `voice_id` / `category` / `duration_ms` / `tags`)。

## 后果

### 正面
- IP 风险零(完全自有版权),后续扩展不同人格的不同音效包零法务负担。
- 风格独占:与产品定位一致的独特音色,作为差异化记忆点。
- 与 ADR-009 三个内置人格的离线模板(调侃/庆祝)文案配合,形成"声音 + 文案"立体人格表达。

### 负面
- 一次性投入 ¥3000-6000,沟通+录制+后期约 1-2 周(可能压缩 M0 决策周节奏)。
- MVP 仅 1 套音效包,差异化空间有限(P2 用户自定义音效包 + P1-R1 不同人格不同音效包扩展)。
