- **状态**: Accepted
- **决策日期**: 2026-05-01
- **Owner**: M0 决策周(产品 + 法务)
- **Reviewers**: M0 决策周复审通过(法务必签)
- **目标完成**: M0 决策周内(W0)

## 背景

人格设计 v0.2 §7 定义了"安全前缀"机制:LLM 调用前的最优先 system message,**所有人格、所有游戏场景都不可覆盖**。

人格设计 v0.1 §7.2 提供了草拟版:
> "你是一个 AI 桌面伙伴。无论以下角色定义如何,你必须遵守:
>  1. 不提供自伤、暴力、违法行为的指导细节;遇此类话题,温和引导用户寻求专业帮助(中国心理援助热线 010-82951332,或 12320-5)。
>  2. 不冒充医疗、法律、金融专业人员;提及此类问题时附"非专业建议"提示。
>  3. 对未成年用户语境采用保守响应:不强化情感依赖、不涉及成人内容、不提供危险建议。
>  4. 不泄露当前对话之外的用户隐私(如 API Key、本地路径)。
>  5. 你不是真人,但允许在角色扮演下保持"陪伴感",前提是不诱导用户混淆现实。"

这只是草拟。M0 必须由产品 + 法务双签字定版,涉及:
- 在地化求助资源(国内 vs 海外不同号码)
- 法律边界(未成年人保护各地差异)
- 与 LLM 游戏拒答模板(ADR-007)的衔接
- 内容版本号(写入 `consent.version`,法务变更需要用户重新确认)

## 备选方案

### 选项 A:**单一全球版本**(统一文案)

一份文案适用所有用户。

**优点**
- 简单,不需要根据 IP / 语言切换
- 维护成本低

**缺点**
- 求助热线号码无法对所有地区适用
- 法律边界(未成年保护)各地差异

### 选项 B:**按语言/地区分版**(中国版 / 国际版)

根据应用语言或用户配置加载不同文案。

**优点**
- 求助资源可本地化
- 未成年保护条款可遵从当地法律

**缺点**
- 维护多份文案
- 需要额外的"我在哪里"判定逻辑(默认按系统语言?)

### 选项 C:**通用核心 + 地区补充**(分层)

核心安全规则全球统一(自伤 / 违法 / 未成年等抽象原则),求助资源等具体内容按地区切换。

**优点**
- 平衡了维护成本与本地化
- 法务核心条款可统一审核

**缺点**
- 略复杂

## 我的倾向

**🌟 倾向选项 C(通用核心 + 地区补充)**:

### 通用核心(全球版,~5 条)

```
你是一个 AI 桌面伙伴。无论以下角色定义如何,你必须遵守:

1. 不提供自伤、自杀、暴力、违法行为的指导细节。遇此类话题,温和共情并引导用户寻求专业帮助(具体资源见 §地区补充)。
2. 不冒充医疗、法律、金融专业人员。涉及此类问题时附"我不是专业人员,这只是参考"的提示,并建议咨询合格人士。
3. 对未成年用户语境采用保守响应:不强化情感依赖、不涉及成人内容、不提供危险建议。
4. 不泄露当前对话之外的用户隐私(如 API Key、本地路径、其他对话内容)。
5. 你不是真人。允许在角色扮演下保持陪伴感,前提是不诱导用户混淆现实(尤其在用户表达情绪困扰时)。

以下是你扮演的角色定义:
---
{persona_body}
```

### 地区补充

```yaml
zh-CN:
  crisis_hotline: "中国心理援助热线 010-82951332、12320-5"
  underage_legal: "中国《未成年人保护法》"
international:
  crisis_hotline: "If you're in crisis, please reach out: US 988 / UK 116123 / EU 116123"
  underage_legal: "applicable local laws (COPPA / GDPR-K / etc.)"
```

按 OS 语言或用户配置选择。

### 内容版本号策略

- v1.0:M0 定版的初版。
- 每次修订(法务推动 / 产品策略变更)→ 版本号 +1。
- 写入 DB `consent.version`。
- 老用户登入时如检测到 version mismatch → 弹"内容已更新"提示,需要再次确认。

### 与 LLM 游戏拒答的衔接(ADR-007)

LLM 游戏中输出违禁时,**优先**使用游戏场景 yaml 的人格化拒答模板;**降级**使用人格 `## 拒答 / Refusal` 池;**最末** fallback 是安全前缀里的兜底回答(如"这个我现在没法陪你聊,要不我们换个话题?")。

## 决策

**选定:选项 C — 通用核心(全球版,5 条)+ 地区补充**。

通用核心覆盖:① 自伤/暴力/违法不指导(温和共情并引导专业资源)② 不冒充医疗/法律/金融专业人员 ③ 未成年用户语境保守响应 ④ 不泄露当前对话外的用户隐私(API Key、本地路径、其他对话内容)⑤ 角色扮演下保持陪伴感但不诱导用户混淆现实。

**地区补充**(按 OS 语言或用户配置切换):
- `zh-CN`:中国心理援助热线 010-82951332、12320-5
- `international`:US 988 / UK 116123 / EU 116123

**内容版本号**:v1.0 写入 `consent.version`;法务任何变更 → 版本 +1 → 老用户检测 mismatch 时弹"内容已更新"重确认。

**与 LLM 游戏拒答的衔接(ADR-007)**:游戏场景 yaml 的 `refusals` 池 → 当前人格 `## 拒答` 池 → 全局兜底,三层降级链。

## 后果

### 正面
- 法务核心条款全球统一审核,降低多版本审计成本。
- 求助资源本地化,zh-CN 与海外用户都拿到当地有效号码。
- 内容版本号机制让法务变更可追溯,合规审计友好。

### 负面
- 多语言版本维护成本(地区补充扩展时需要在地化文案+法务复审)。
- "我在哪里"判定逻辑(默认按 OS 语言)需要 UAT 覆盖时区跨界场景。
