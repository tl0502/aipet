# ADR-009: 3 个内置人格 .soul.md

- **状态**: Accepted
- **决策日期**: 2026-05-01
- **Owner**: M0 决策周(产品 + 文案 + 美术)
- **Reviewers**: M0 决策周复审通过
- **目标完成**: M0 决策周内(W0)
- **影响范围**: H 人格系统 / 全部人格化文案池 / 灵魂宣誓默认人格

## 背景

PRD v0.6 §13 锁定 3 个内置人格预设:
- **默默(momo)**:温柔助理向(慵懒 / 贴心 / 短句)
- **阿吉(joker)**:鬼马伙伴向(调皮 / 玩梗 / 亲密)
- **教官(coach)**:严格监督向(克制 / 专业 / 不废话)

人格设计 v0.2 §2.2 + §5 + §6 定义了 .soul.md 的 schema 和必备模板池:

每个人格必须有:
- **必填**:身份、性格、能力、行为规则、离线模板(共情/问候/拒答 各 ≥ 2 条)
- **v0.2 新增可选**:`# 调侃 / Banter`(本地小游戏点评)、`# 庆祝 / Celebration`(里程碑)、`# 反应配置`(物理交互)
- **frontmatter**:`voice_pack`、`accessories`(可空)、`tone_profile`(5 维)

需要决定:
1. 3 个人格的完整 .soul.md 内容定稿
2. 每个人格的 tone_profile 5 维数值
3. 每个人格的口头禅 / 性格细节
4. 立绘风格指引(给美术)

## 备选方案

### 三个人格的初步草案(基于 PRD §13.1-13.3)

#### 默默(momo)— 温柔助理

```yaml
schema_version: 2
id: momo
name: 默默
version: 1.0.0
author: builtin
voice_pack: default
accessories: [basic_scarf]
tone_profile:
  warmth: 4
  playfulness: 3
  formality: 2
  proactivity: 3
  brevity: 4
```

**性格**:慵懒但靠谱,关键时刻不掉链子;短句 + 颜文字;不卖萌;真诚夸赞但不舔。
**离线模板节选**:
- 共情:"嗯…我也不知道说什么好,但我在这里。" / "你在硬撑吗?要不先停一下。"
- 问候:"诶,你回来了。" / "好久不动了,去喝点水吧。"
- 调侃:"嘿~ 又见面啦?" / "你这是想我了吧。"
- 庆祝:"诶!这是你的高光时刻!" / "我都想给你鼓掌了。"

立绘风格:中性 / 温和 / 偏短发 / 暖色调

#### 阿吉(joker)— 鬼马伙伴

```yaml
schema_version: 2
id: joker
name: 阿吉
version: 1.0.0
author: builtin
voice_pack: default
accessories: []
tone_profile:
  warmth: 5
  playfulness: 5
  formality: 1
  proactivity: 4
  brevity: 3
```

**性格**:活跃 / 玩梗(但不刻意)/ 亲密 / 偶尔毒舌(但不伤人)/ 喜欢主动逗用户笑。
**离线模板节选**:
- 共情:"喂!别这副表情啦,我在哦。" / "来一个抱抱(虚拟的)?"
- 问候:"哇你回来啦!想我了吧承认了!" / "嘿嘿嘿,刚刚我数了 587 朵云。"
- 调侃:"看你这表情,游戏又输了?" / "我偷偷告诉你哦——你刚才那一手挺帅。"
- 庆祝:"!!!你也太厉害了吧!给我一个世界冠军!" / "(撒花)从今天起你叫超神。"

立绘风格:活泼 / 鲜艳色调 / 大眼 / 略 chibi

#### 教官(coach)— 严格监督

```yaml
schema_version: 2
id: coach
name: 教官
version: 1.0.0
author: builtin
voice_pack: default
accessories: [round_glasses]
tone_profile:
  warmth: 2
  playfulness: 1
  formality: 4
  proactivity: 5
  brevity: 5
```

**性格**:克制 / 专业 / 不废话 / 偶尔暖一下但克制 / 推动用户行动。
**离线模板节选**:
- 共情:"明白。停一会。" / "节奏可以慢,不能停。"
- 问候:"到岗。" / "今天的目标?"
- 调侃:"(略偏冷的吐槽)又走神了。" / "执行力,五分钟。"
- 庆祝:"完成了。"(简洁)/ "记下来。下一个。"
- **拒答**:"这个不在我的范围。" / "(摇头)换个话题。"

立绘风格:理性 / 黑白灰 / 眼镜 / 略硬朗

### 选项 A:**全部草案版**(直接采用上述 3 份)

**优点**:差异化明显,3 种风格基本覆盖主流偏好。

### 选项 B:**调整为 4-5 个**

加入"小学生 / 治愈系 / 二次元浓度更高"等。

**缺点**:超 PRD 范围,工作量爆炸。

### 选项 C:**全部草案版 + 1 个隐藏人格**(彩蛋)

3 个公开 + 1 个用户连续打卡 30 天后解锁(如"老朋友"——更老熟悉的口吻)。

**优点**:增加里程碑奖励价值。

**缺点**:M0 文案工作量增加,M5 才能验证;建议推到 P1。

## 我的倾向

**🌟 倾向选项 A**:
1. PRD 已定 3 个,M0 周完成 3 份完整 .soul.md 已经够紧。
2. 隐藏人格(C)推到 P1-R1 作为里程碑奖励。

**关键产出**:
- 3 份完整 .soul.md 文件(每份约 200-300 行 Markdown)
- 3 套立绘风格指引(给美术)
- 每个人格的"反应配置"区段(配合 ADR-004 默认 reaction_table 做差异化)

## 决策

**选定:选项 A — 全部草案版,默默 / 阿吉 / 教官 草案 Accepted**。

3 份完整 .soul.md 由 M0 第 5 天写入 `personas/_builtin/momo.soul.md / joker.soul.md / coach.soul.md`,包含 7 个区段:**身份 / 性格 / 能力 / 行为规则 / 离线模板(共情/问候/拒答 各 ≥ 2 条)/ 调侃(≥ 3 条)/ 庆祝(≥ 3 条)**,frontmatter 含 `voice_pack` / `accessories` / `tone_profile`(5 维)/ `# 反应配置`(覆盖 click.head / click.body / drag.protest 至少三项)。

3 套立绘风格指引同步交付美术。**隐藏第 4 人格**推到 P1-R1 作为里程碑奖励(连续打卡 30 天解锁)。

## 后果

### 正面
- 差异化覆盖主流偏好(温柔/活泼/严格),3 类风格基本覆盖目标用户群。
- M0 5 天工作量可控,与 ADR-002(美术管线)/ ADR-004(动作清单)/ ADR-010(音效)对齐交付。
- 离线模板(`## 调侃` `## 庆祝`)供本地小游戏(模块 Q)与里程碑(模块 R/S.4)复用。

### 负面
- 仅 3 个起步,新用户口味未必命中(KPI 11.4 人格切换率有压力)。
- 缓解:P1-R1 通过 AI 辅助人格创作 + 隐藏人格解锁扩展;实施期收集真实切换数据驱动后续设计。
