# ADR-014: 本地小模型候选(P1-R3 探索)

- **状态**: Accepted(方向确认,实施推迟到 P1-R3)
- **决策日期**: 2026-05-01
- **Owner**: M0 决策周(产品 + 工程)
- **Reviewers**: M0 决策周复审通过
- **目标完成**: M0 决策周已确认方向;具体模型/版本基线在 P1-R3 启动前(M9+)重新 benchmark
- **影响范围**: 离线对话生成能力(P1-R3 探索)

## 背景

PRD v0.6 §5.2(P1-R3)规划:本地小模型对话作为离线生成回复来源。

当前 v0.6 的离线策略是"规则回复 + 人格化模板",已能保证 MVP 离线可用。本地小模型的引入是**增强**,不是必需。

需要 P1-R3 启动前决定:
1. 候选模型(Phi-3.5-mini / Qwen2.5-3B / 其他)
2. 量化策略(Q4 / Q5 / Q8)
3. 推理后端(llama.cpp / Ollama / ONNX Runtime / Candle)
4. 资源占用边界

## 候选模型对比

| 模型 | 参数量 | Q4 内存 | Q4 体积 | 中文能力 | 推理速度(消费级 CPU,t/s) |
|---|---|---|---|---|---|

| **Qwen2.5-3B-Instruct** | 3B | ~2GB | ~1.8GB | ★★★★★ | 10-18 |

## 推理后端对比

### 选项 A:**llama.cpp + GGUF**

直接 link `llama.cpp` 静态库到 Tauri Rust 主进程。

**优点**
- 体积最小,无外部依赖
- 跨平台
- 支持几乎所有 GGUF 模型

**缺点**
- 集成有一定 Rust FFI 工作量
- 升级 llama.cpp 时需要重新编译

### 选项 B:**调用本地 Ollama**

要求用户安装 Ollama,通过 HTTP API 调用。

**优点**
- 用户已习惯 Ollama,模型管理方便
- 我们零集成成本(已经在 ADR-005 LLM Provider preset 里支持)

**缺点**
- 用户需要单独安装 Ollama(< 1GB)
- 不算"内嵌本地小模型"

### 选项 C:**ONNX Runtime + ONNX 模型**

用 ONNX Runtime + 量化的 ONNX 模型。

**优点**
- 跨平台稳定
- ONNX 生态成熟

**缺点**
- 转 ONNX 不一定都顺利
- 体积比 GGUF 通常大

### 选项 D:**Candle**(Rust 原生)

HuggingFace 的 Rust 推理库。

**优点**
- 纯 Rust,集成无 FFI
- 与 Tauri 完美契合

**缺点**
- 生态比 llama.cpp 小
- 部分模型未必支持

## 我的倾向

**M9+ 决策时偏向 Qwen2.5-3B(Q4)+ 用户已装 Ollama 走 ADR-005 默认 provider**(即选项 B):

1. **不内嵌**减少 MVP 包体积
2. 用户已配置 Ollama → 自动可用(零额外工作)
3. Qwen2.5 中文能力在 3B 级别最强

如果未来希望"零依赖"内嵌 → 选项 A(llama.cpp + Qwen2.5-3B-Q4),包体积 +1.8GB(可作为可选下载,首次需要时再拉)。

## 决策

**选定:选项 B — 调用本地 Ollama**(MVP 不内嵌,P1-R3 启用)。

MVP 不内嵌任何模型;用户在设置中可配置 `base_url=http://localhost:11434/v1` 走 OpenAI 兼容协议(已含在 ADR-005 preset 第 5 项)。**推荐模型**:Qwen2.5-3B-Instruct-Q4(中文最佳,~2GB 内存,8-15 t/s 消费级 CPU)。

**M9+ 实施期决策点**(本 ADR 不锁,留待 P1-R3 重新 benchmark):
- 候选模型重测(Qwen2.5 / Phi-3.5 / Llama 3.2 等可能已迭代)
- 是否补充选项 A(llama.cpp + GGUF 内嵌,首次启用时按需下载 ~2GB)
- UI:用户启用本地小模型的开关位置 + 性能基线(首 token < 3s,内存 ≤ 3GB)

## 后果

### 正面
- 零集成工作:用户已装 Ollama 即可用,不增加 MVP 包体积(满足 PRD §10.5 总安装包 ≤ 80MB)。
- 与 ADR-005 LLM Provider 抽象自然融合,不引入新代码路径。
- 决策可逆:P1-R3 真实数据驱动是否补充内嵌路径(选项 A)。

### 负面
- 用户需要单独安装 Ollama(< 1GB),不算"完全开箱即用的本地小模型"。
- Qwen2.5-3B 中文能力虽强,但比云端 GPT-4o-mini / DeepSeek 仍有差距;离线生成回复质量有上限(P1-R3 评估时若无法满足留存目标需启用选项 A)。
