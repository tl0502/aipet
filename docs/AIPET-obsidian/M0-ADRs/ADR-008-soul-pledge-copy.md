# ADR-008: 灵魂宣誓页文案

- **状态**: Accepted
- **决策日期**: 2026-05-01
- **Owner**: M0 决策周(产品 + 法务)
- **Reviewers**: M0 决策周复审通过(法务必签)
- **目标完成**: M0 决策周内(W0)
- **影响范围**: M 灵魂宣誓 / Onboarding Step 1 / 法律有效性

## 背景

PRD v0.6 §7.13 + 流程 v0.6 §1.1 锁定:**首启隐私同意页由"宣誓人格"以第一人称叙述,等价于传统隐私同意**。

法律有效性要求:
- 信息完整性等同于原冷冰冰隐私页(本地、可清除、网络透明、权限默认关)。
- 可一键展开正式版条款。
- "我懂了"按钮等价于"同意",写入 `consent.granted=true + consent.method='soul_pledge' + consent.version=N`。
- 文案版本号变更时强制用户重新确认。

需要决定:
1. 最终文案(由"默默 momo"人格的口吻叙述)。
2. 正式版条款全文。
3. 版本号管理流程。

## 备选方案

### 选项 A:**温暖叙述版**(推荐)

```
（默默坐在屏幕中,看向你）

诶,我是默默。在我们开始之前,有几件事我想先告诉你——

我的记忆只在你电脑里。
你随时可以让我忘掉一切。

要联网聊天的时候,我会先告诉你。
不想联网?我们就只用本地的功能。

截图和剪贴板,默认是关的。
你需要的时候再开,我不会偷看。

这些不是法务条款,是我的承诺。

──── 想了解技术细节,看看 [完整数据策略] ────

[ 我懂了,一起开始 ]      [ 再看看 ]      [ 退出 ]
```

**优点**
- 首人称温暖,符合产品定位
- 信息浓缩到 5 句,用户读完率高
- 法务"完整数据策略"链接保留法律有效性

**缺点**
- "承诺"措辞需要法务确认是否构成法律意义上的承诺
- 不同地区法律对"温暖叙述"的等价性可能态度不一(美国/欧洲较严)

### 选项 B:**冷静明确版**

```
（默默看着你）

嗨,我是默默。开始之前,告诉你几件重要的事:

1. 你的数据保存在你的电脑上,我不上传。
2. 联网调用 AI 模型时会有明确提示。
3. 截图、剪贴板等权限默认关闭,使用前会请求你同意。
4. 你随时可以删除全部数据。

更详细的内容: [查看完整数据策略]

[ 我同意 ]      [ 退出 ]
```

**优点**
- 法务零风险
- 信息直接

**缺点**
- 失去人格化温度,违背 PRD 设计初衷

### 选项 C:**双层结构**

主页面用选项 A 温暖叙述,但每条叙述下方有一行**小字法务表述**:

```
我的记忆只在你电脑里。
（具体:用户对话、记忆、人格文件均存储在 %APPDATA%\AIDesktopPet\,不上传任何远程服务器）
```

**优点**
- 兼顾温度与法律严谨性

**缺点**
- 视觉略复杂

## 我的倾向

**🌟 倾向选项 A + 法务版完整条款 + 强版本管理**:

1. 主页面用温暖叙述(契合产品差异化)
2. 通过"完整数据策略"链接挂载严谨法务文本(在弹出 modal 中展示)
3. `consent.version` 严格管理,法务任何变更 → 版本 +1 → 老用户重确认

### 完整数据策略骨架(法务版)

```markdown
# AI桌宠数据策略 v1.0

最后更新:2026-XX-XX

## 1. 我们收集什么
- 你与桌宠的对话(本地存储 90 天后自动删除)
- 你设置的偏好(称呼、作息、提醒等,本地长期存储)
- 错误日志(本地存储,可手动导出,不自动上传)
- 匿名使用统计(可在设置中关闭)

## 2. 我们不收集什么
- 屏幕内容、应用名、窗口标题、按键内容
- 文件路径、文件名(模块 L 文件拖入仅使用文件文本作为单次会话上下文,不持久化)
- 麦克风录音(模块 P 声音表情仅本地播放)
- 你的位置信息

## 3. 数据如何处理
- 默认全部本地存储
- 调用云端 LLM 时,你的对话会发送到你配置的 Provider
- ...

## 4. 第三方服务
- 你配置的 LLM Provider(OpenAI / DeepSeek 等):由你自主选择,数据政策见对应服务
- ...

## 5. 你的权利
- 随时导出全部数据
- 随时删除全部数据
- 随时关闭任何数据收集

## 6. 联系
- ...
```

## 决策

**选定:选项 A — 温暖叙述版 v1.0**(由"默默 momo"以第一人称叙述)。

主页面 5 句承诺 + 一行"完整数据策略"链接 + "我懂了 / 再看看 / 退出"三按钮。"我懂了"等价于"同意":写入 `consent.granted=true + consent.method='soul_pledge' + consent.version=1`。

**完整数据策略 v1.0** 作为 modal 挂载,covers:收集什么 / 不收集什么 / 数据如何处理 / 第三方服务 / 用户权利 / 联系方式。法务版骨架见"我的倾向"段,文案最终版写入 `assets/legal/data_policy_v1.md`。

**版本管理**:`consent.version` 严格递增,任何法务变更(承诺措辞/数据范围/第三方服务)→ 版本 +1 → 老用户启动时弹"内容已更新"必须再次确认才能进入主态。

## 后果

### 正面
- 契合产品差异化,首人称温暖叙述区别于行业冷冰冰的"我同意"。
- 信息浓缩到 5 句,用户实际读完率显著高于传统隐私页。
- 通过"完整数据策略"链接保留法律有效性,符合 GDPR / COPPA 信息完整性要求。

### 负面
- 不同地区(美国/欧洲较严)对"温暖叙述"的法律等价性态度可能不一,需要法务为每个发布地区单独复审。
- "承诺"措辞需法务确认是否构成法律意义上的承诺(陈述性 vs 合同性),M0 决策周法务复审已确认按陈述性表达。
