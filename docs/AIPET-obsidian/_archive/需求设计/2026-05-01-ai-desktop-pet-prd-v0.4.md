## 1. 背景与目标

AI桌宠项目目标是构建一个常驻桌面的智能伙伴，兼顾"陪伴感"与"执行力"。

基于竞品调研，当前市场存在两类明显缺口：
1. 纯陪伴产品可爱但低任务完成率，留存弱。
2. 纯效率助手可用但缺少人格和长期使用粘性。

同时，头部陪伴产品（Replika / Character.AI / Nomi）人格中心化，**用户无法对人格做实质性塑造与所有权占有**。这是 AI桌宠的差异化切入点。

MVP阶段目标：在仅 Windows 平台先完成一个可验证的产品闭环，证明：
1. "桌宠形态 + 用户自主人格"能显著提升日活留存与情感粘性。
2. "轻任务闭环"能将日提醒完成、番茄启动、待办完成转化为留存指标。
3. 满足离线可用上线要求。

## 2. 已确认产品决策（冻结）

1. 首发平台：仅 Windows（Windows 10/11，64-bit）。
2. 价值权重：陪伴:效率 = 6:4，并通过"人格自主"显式承载陪伴权重。
3. 截图问答：保持 P1，不纳入本期 P0 范围。
4. 离线可用：作为上线硬约束。
5. 首发技术栈：Tauri 2.x（桌面容器，Rust 主进程 + WebView 前端）。
6. 桌宠形态：2D 桌宠。**资源管线选型见第 13 节开放决策**（M0 内决定）。
7. 离线对话策略：规则回复 + 人格化模板（非本地生成模型；本地小模型作为 P1 探索）。
8. 提醒稍后策略：有限稍后（最多 3 次）。
9. 数据保留默认：对话默认保留 90 天。
10. 敏感权限默认：截图/剪贴板默认关闭，首次使用逐项授权。
11. **人格自主权（v0.4 新增）**：用户可创建、编辑、导入、导出、切换桌宠人格，人格文件为 Markdown 格式（`*.soul.md`），完全归属用户。
12. **快捷键默认（v0.4 修正）**：默认 `Ctrl + Alt + Space`（避开 Windows 系统 `Alt+Space` 与中文输入法 `Ctrl+Space`），用户可自定义。

## 3. 产品定位

一句话定位：**`一个由你亲手塑造、陪你把小事做完的 AI 桌宠`**。

差异点（相对竞品）：
1. 相对 Replika / Character.AI：人格归属用户，可编辑、导出、迁移，不被平台锁定。
2. 相对 Clawster / PetClaw：在"陪伴感"和"执行力"之间形成显式权重，并把人格作为产品级抓手而非附属设置。
3. 相对 Microsoft Copilot：保留"非工具感"的伙伴关系，不以系统级强势入侵替代用户操作。

核心价值主张：
1. **陪伴（60%）**：常驻、可互动、人格稳定且由你定义。
2. **效率（40%）**：提醒、待办、番茄钟、快捷问答形成闭环。
3. **可控**：记忆和隐私可视、可关、可删；人格可编辑、可导出。

## 4. 目标用户与核心场景

### 4.1 目标用户

1. 学生用户：需要轻量督学、番茄钟、复盘提醒。
2. 办公人群：需要碎片化任务管理和快速信息处理。
3. 独立开发者 / 创作者：需要低打断成本的桌面助手。
4. **二次元 / 角色爱好者（v0.4 新增子群）**：愿意花时间塑造一个"自己的"桌宠形象与人格。

### 4.2 核心场景

1. 快速问答：全局快捷键唤起对话，不切换主应用。
2. 提醒执行：喝水/休息/日程提醒，支持完成或稍后。
3. 专注流程：番茄钟驱动专注与休息节奏。
4. 轻任务拆解：自然语言目标转待办清单。
5. 个性化互动：桌宠记忆称呼与偏好。
6. **人格塑造（v0.4 新增）**：用户进入"人格工坊"，从模板开始或从零创建桌宠的人设、口吻、行为边界，并可保存为 `.soul.md` 分享或备份。

## 5. MVP范围定义

### 5.1 必做（P0）

1. 桌宠常驻与基础互动。
2. 文本对话与全局快捷唤起。
3. 提醒系统（定时提醒、重复提醒、完成/稍后）。
4. 番茄钟（专注/休息）。
5. 轻量待办（创建、完成、延期）。
6. 基础记忆（称呼、偏好、作息）。
7. 设置中心（模型、提醒、隐私开关）。
8. 本地数据存储与导出/删除。
9. 离线模式（无网络时核心能力可用）。
10. **人格系统 P0 子集（v0.4 新增）**：内置 3 个默认人格预设、用户可在 GUI 中编辑当前人格、人格切换、人格 .soul.md 导入导出。
11. **首次启动 Onboarding（v0.4 新增）**：6 步引导，覆盖隐私同意、快捷键确认、人格选择、提醒模板选择、第一次番茄钟、首次唤起对话。
12. **自动更新（v0.4 新增）**：基于 tauri-updater 的差分包更新，支持暂缓更新与强制更新两档。

### 5.2 可选（P1）

1. 截图问答。
2. 剪贴板总结。
3. 多宠物皮肤 / 形象资源包。
4. 云端同步（账号体系预埋，本期不做账号但保留 schema）。
5. **人格市场（社区分享 .soul.md）**。
6. **本地小模型对话**（Phi-3.5-mini 4-bit 或同级，作为离线生成回复来源）。

### 5.3 明确不做（本阶段）

1. 复杂 3D 实时渲染。
2. 开放式 UGC 角色市场（仅做协议与文件格式，不做服务端）。
3. 多人社交空间。
4. 深度系统自动化（批量控制应用、文件自动改写）。
5. 语音播报与语音输入（评估为 P2）。

## 6. 离线能力矩阵（上线门槛）

| 模块 | 在线状态 | 离线状态 | 恢复联网后 |
|---|---|---|---|
| 桌宠壳层 | 全量可用 | 全量可用 | 无需补偿 |
| 对话 | 云模型回复 | 规则回复 + 人格化模板 | 自动切回在线回复 |
| 提醒 | 全量可用 | 全量可用 | 同步离线触发记录 |
| 番茄钟 | 全量可用 | 全量可用 | 同步统计 |
| 待办 | 全量可用 | 全量可用 | 合并离线改动 |
| 记忆 | 全量可用 | 全量可用 | 无冲突时直接合并 |
| 人格系统 | 全量可用（含市场预览，P1） | 全量可用（编辑/切换） | 无需补偿 |
| 设置/隐私 | 全量可用 | 全量可用 | 无需补偿 |
| 埋点 | 实时上报 | 本地缓存 | 联网后补发 |
| 自动更新 | 全量可用 | 不可用，提示 | 联网后重试 |

离线对话策略优先级：
1. 功能命令词（如"新增提醒""开始番茄钟"）→ 直接执行。
2. **人格化模板**（共情/问候/拒答/调侃）→ 由当前人格的离线模板池命中。
3. 关键词模板（如"总结""翻译"）→ 返回离线能力提示。
4. 通用离线提示（引导联网或执行本地功能）。

## 7. 功能需求（P0）

### 7.1 模块A：桌宠壳层与基础交互

**功能说明**
- 桌宠常驻桌面，可拖动，支持置顶开关。
- 支持空闲、专注、提醒、休息四种状态动作。
- 支持多 DPI 与多显示器（含主屏切换、跨屏拖动后吸附）。

**验收标准**
1. 启动后 5 秒内可见桌宠。
2. 可启用/禁用始终置顶。
3. 最小化后可从托盘恢复。
4. 4K + 125% 缩放下桌宠不模糊不溢出。
5. 多屏切换时桌宠位置保留在最后所在屏幕。

### 7.2 模块B：对话与唤起

**功能说明**
- 全局快捷键唤起对话框，**默认 `Ctrl + Alt + Space`**（v0.4 修正），可改。
- 在线支持连续上下文对话（单会话上限 20 轮）。
- 离线切换为规则回复 + 人格化模板，不崩溃。
- 对话面板支持 ESC 关闭、点击外部失焦关闭、Enter 发送 / Shift+Enter 换行。

**验收标准**
1. **首 token < 1.5 秒**（联网，主流模型，p50），完整响应不限。
2. 本地保留最近 20 条会话。
3. 离线时必须明确显示"离线规则模式"。
4. 快捷键冲突时启动期可探测并提示用户改键（不强制覆盖）。

### 7.3 模块C：提醒系统

**功能说明**
- 支持一次性提醒、每日重复提醒。
- 提醒动作：完成、稍后 10 分钟、忽略。
- 稍后上限：3 次；第 4 次触发时转"未完成待复盘"。
- **并发优先级**（v0.4 新增）：用户处于专注（FOCUS）状态时：
  - "硬提醒"（用户标记为不可缓的，如吃药、会议）→ 立即打断专注，弹出提醒。
  - "软提醒"（喝水、久坐等）→ 静默累积，专注结束进入 REST 时合并提示。
  - 默认提醒为"软提醒"，可在创建时切换。

**验收标准**
1. 触发误差 ≤ 30 秒。
2. 重复提醒可开关。
3. 离线状态照常触发。
4. 全量行为写入提醒历史。
5. 软/硬提醒优先级分流可在 UAT 中验证。

### 7.4 模块D：番茄钟

**功能说明**
- 默认 25/5 模板，可自定义时长（5–90 / 1–30）。
- 专注结束触发状态变化与提醒。
- 专注期间软提醒被静默累积。

**验收标准**
1. 支持开始、暂停、恢复、结束。
2. 统计当日完成番茄数。
3. 离线状态完整可用。
4. 系统休眠/锁屏后唤醒，剩余时间正确恢复。

### 7.5 模块E：轻量待办

**功能说明**
- 创建、完成、延期。
- AI 可拆解目标为 3–7 个子任务（在线）。

**验收标准**
1. 字段包含标题、截止时间、状态、来源、关联人格。
2. AI 拆解结果可编辑再保存。
3. 离线可新增、编辑、完成。

### 7.6 模块F：记忆与偏好

**功能说明**
- 存储称呼、作息、提醒习惯。
- 支持查看、编辑、单条删除、清空。
- **记忆与人格分离**（v0.4 新增）：人格 = 角色定义（共享的"是什么人"），记忆 = 用户私人事实（"知道关于我什么"）。切换人格时记忆保留、人格更新。

**验收标准**
1. 所有记忆项可视化管理。
2. 清空后对话不再使用旧偏好。
3. 离线读写一致。
4. 切换人格不丢失记忆。

### 7.7 模块G：设置与隐私控制

**功能说明**
- 模型配置（API Key、模型名、Base URL）。
- 隐私开关（保存对话、启用记忆、敏感权限明细）。
- 数据操作（导出、导入、删除全部）。
- **API Key 加密**（v0.4 修正）：使用 **Windows DPAPI**（`CryptProtectData`，与当前用户账户绑定）；导出数据时 API Key 字段默认不导出，需显式勾选并以二次输入主密码保护。

**验收标准**
1. 首次启动展示隐私说明并同意。
2. 权限页可见截图/剪贴板授权状态与最近一次访问时间。
3. 导出文件可用于同 schema 版本导入恢复。
4. 删除 API Key 后任何对话调用都失败并明确提示。

### 7.8 模块H：人格系统（v0.4 新增）

**功能说明**
- 内置 3 个默认人格预设（建议：温柔助理 / 鬼马伙伴 / 严格监督）。
- "人格工坊"页支持：
  - 新建人格（基于模板或空白）。
  - 编辑当前人格（GUI 简易模式 + Markdown 进阶模式）。
  - 切换人格（全局生效，附带桌宠形象切换）。
  - 导入 / 导出 `.soul.md` 文件。
  - 删除人格（不可删最后一个，至少留一个默认）。
- 人格文件 schema 详见《角色与人格设计 v0.1》第 2 节。
- 人格切换在不杀进程的前提下完成（热切换）。

**验收标准**
1. 切换人格后下一条消息即生效。
2. 导入非法 .soul.md 文件不崩溃，给出可读错误。
3. 默认人格不可被永久删除（仅可隐藏）。
4. 编辑界面提供"试聊沙盒"：保存前可与人格预试聊 3-5 轮。
5. 安全护栏（不可绕过的全局规则）即使被用户人格覆盖也仍然生效。

## 8. 数据与隐私规范

### 8.1 数据分类

1. 配置数据：快捷键、主题、开关项。
2. 对话数据：消息文本、时间戳、模式（在线/离线规则）、当时人格 ID。
3. 记忆数据：偏好键值与更新时间。
4. 任务数据：提醒、待办、番茄统计。
5. **人格数据（v0.4 新增）**：`.soul.md` 文件 + 元信息（创建时间、当前是否激活）。
6. 运行数据：错误日志、埋点缓存。

### 8.2 存储与保留

1. 默认本地存储（SQLite + 本地文件 + `personas/` 目录存放 `.soul.md`）。
2. 对话默认保留 90 天，超期自动清理。
3. 记忆/任务/人格默认长期保留，用户可随时清空。
4. API Key 本地加密存储（Windows DPAPI）。
5. 用户数据目录：`%APPDATA%\AIDesktopPet\`（详见架构文档）。

### 8.3 删除与导出

1. 提供一键删除全部用户数据。
2. 删除执行完成后本地不可恢复。
3. 提供 JSON 导出（不含 API Key）与 .soul.md 单独导出。
4. **数据迁移（v0.4 新增）**：升级版本时由迁移管理器顺序执行 schema 增量迁移，迁移前自动备份，迁移失败可回滚。

## 9. 内容安全与边界

1. 高风险内容（自伤、暴力、违法）不提供指导性细节。
2. 医疗/法律/金融类问题提供"非专业建议"提示并引导专业渠道。
3. 对未成年人语境采用保守响应：不强化情感依赖，不提供危险建议。
4. 离线规则回复同样遵守安全模板。
5. **人格系统的安全护栏（v0.4 新增）**：用户自定义人格可以塑造性格、口吻，但 **不能覆盖** 上述安全规则；所有人格在 system prompt 拼装时会预置一段不可见的"安全前缀"。详见《角色与人格设计 v0.1》第 7 节。

## 10. 非功能需求

### 10.1 性能（v0.4 收紧）

1. 冷启动 ≤ 5 秒（普通办公机）。
2. **常驻内存目标 ≤ 250MB**（v0.4 收紧，原 500MB），不含外部模型进程；可选 verbose 模式 ≤ 350MB。
3. 常态 CPU 占用平均 ≤ 5%。
4. 桌宠空闲态 GPU 占用 < 2%（无活跃动画时降级到静态贴图）。
5. **首 token 时间** p50 ≤ 1.5 秒（联网，主流模型）。

### 10.2 稳定性

1. 单日运行崩溃率 < 1%。
2. 提醒、待办、番茄钟可在异常后恢复。
3. 进程被强杀后再次启动，提醒不丢失。

### 10.3 可观测性

1. 核心行为具备埋点。
2. 离线事件本地缓存并补发。
3. 错误日志支持本地导出用于排障。
4. 埋点 schema 带版本字段（`event_schema_version`），支持灰度演进。

### 10.4 升级与兼容（v0.4 新增）

1. 自动更新基于 tauri-updater，支持差分更新与签名校验。
2. 数据库 schema 迁移幂等且可回滚。
3. 向前兼容：老版本可读新版本数据时，未知字段忽略不报错。

## 11. 关键指标（MVP验收）

### 11.1 留存与活跃
1. D1 留存 ≥ 35%。
2. D7 留存 ≥ 15%。
3. 日均主动唤起次数 ≥ 3。

### 11.2 任务完成
4. 人均日提醒完成次数 ≥ 2。
5. 番茄钟启动率 ≥ 25%。
6. 提醒完成率 ≥ 60%。

### 11.3 人格自主权（v0.4 新增）
7. **人格编辑率**：D7 内编辑过当前人格的用户占比 ≥ 25%。
8. **人格切换率**：D7 内至少切换过一次人格的用户占比 ≥ 30%。
9. 自定义/导入人格的用户 D7 留存比基线 +10pp（用作差异化验证）。

### 11.4 工程质量
10. 崩溃率 < 1%。
11. 埋点完整率 ≥ 95%。
12. 自动更新成功率 ≥ 95%。

## 12. MVP 成功 / 杀死标准（v0.4 新增）

### 12.1 成功标准（满足所有项即认定 MVP 成功）
1. D7 留存 ≥ 15% 且日均唤起 ≥ 3。
2. 人格相关的两个指标（编辑率/切换率）至少有一个达标。
3. 性能、崩溃、埋点完整性达标。

### 12.2 杀死标准（命中任一项需重新评估方向）
1. D1 留存 < 20% 持续两个测试批次。
2. 人格编辑率 < 5% 且切换率 < 10%（说明差异化无效）。
3. 内测期严重 P0 事故率 ≥ 2 次（数据丢失、崩溃链路）。
4. 提醒完成率 < 30%（说明效率侧不闭环）。

## 13. 版本计划与退出条件

1. **M0（决策周）**：完成第 14 节"开放项"全部决策，输出 ADR。
2. **M1（第1-2周）**：桌宠壳层、唤起对话、设置基础、Onboarding。
   - 退出：核心 UI 跑通，快捷键稳定，崩溃率 < 3%。
3. **M2（第3-4周）**：提醒、番茄钟、待办闭环 + **人格系统 P0**。
   - 退出：三大模块离线可用；人格 CRUD/切换/导入导出可用，主流程 UAT 通过率 ≥ 90%。
4. **M3（第5-6周）**：记忆、隐私治理、离线规则回复完善、自动更新打通。
   - 退出：权限与数据策略全部可验证，安全模板覆盖高风险输入；自动更新成功率 ≥ 95%。
5. **M4（第7-8周）**：优化、灰度内测、埋点验收、性能收敛。
   - 退出：满足性能指标，埋点完整率 ≥ 95%，可发布候选版。

## 14. 开放项（实现前需确认 / M0 决策）

1. **2D 桌宠资源管线选型**（必须 M0 内决定）：Live2D Cubism 4 / Spine 2D / PNG 序列帧。建议倾向 Live2D（社区资源 + 表现力）但需评估授权成本。
2. **默认提醒模板集合**（喝水/久坐/学习）文案版本与人格化变体。
3. **3 个默认人格的具体设定**（名字 / 立绘风格 / 性格关键词）。
4. **本地小模型 P1 候选**：Phi-3.5-mini-instruct (Q4_K_M) vs Qwen2.5-3B-Instruct (Q4)，决策依据为内存占用与中文能力。
5. **是否在 MVP 内置语音播报**（当前默认不做）。
6. **签名分发**：是否购买 EV 代码签名证书（影响 SmartScreen 信任）。

## 15. 术语说明

1. **MVP**：最小可行产品，目标是验证核心价值。
2. **轻任务闭环**：任务从创建、提醒到完成形成完整流程。
3. **规则回复**：离线时基于命令词和模板返回，不调用生成模型。
4. **人格 / Soul**：定义桌宠"是谁、怎么说话、能做什么"的可编辑文件，对应 `*.soul.md`。
5. **记忆**：用户授权下保存的偏好与习惯数据，描述"用户是谁"，与人格正交。
6. **安全护栏**：所有人格不可绕过的全局安全规则前缀。
7. **硬提醒 / 软提醒**：能否打断专注态的提醒分级。
