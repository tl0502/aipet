## 1. 背景与目标

AI桌宠项目目标是构建一个常驻桌面的智能伙伴，三大支柱：
1. **陪伴感**（人格自主 + 主动陪伴 + 仪式感 + 物理交互）。
2. **执行力**（轻任务闭环：提醒、待办、番茄钟、文件交互）。
3. **娱乐性**（小游戏、装扮、声音表情、桌宠日常）。

MVP 核心命题（v0.6 升级版）：用"用户自主人格 + 主动关心 + **共同活动**"的组合，证明：
1. 桌宠形态 + 用户自主人格能显著提升日活留存与情感粘性。
2. 主动关心是陪伴产品的护城河。
3. **共同活动（游戏 / 仪式 / 装扮 / 物理回应）让陪伴从"它在那里"升级到"我们在一起"**（v0.6 新增）。
4. 满足离线可用上线要求。

## 3. 产品定位

一句话定位：**`一个由你亲手塑造、会主动关心你、能和你一起玩的 AI 桌宠`**（v0.6 升级口号）。

差异点：
1. 相对 Replika / Character.AI：人格归属用户。
2. 相对 Clawster / PetClaw：主动陪伴 + **共同活动**。
3. 相对 Microsoft Copilot：保留"非工具感"的伙伴关系。
4. **相对 Desktop Mate（Steam）**：兼具"陪伴"与"效率"两条线，并且人格用户可自主塑造。

核心价值主张：
1. **陪伴（60%）**：常驻、有生命感、主动关心、人格由你定义、**和你一起玩**。
2. **效率（40%）**：提醒、待办、番茄钟、快捷问答、文件交互形成闭环。
3. **可控**：记忆和隐私可视、可关、可删；人格可编辑、可导出。

  - 昵称作为 `memory.pet_nickname` 持久化。
  - 切换人格时昵称重置为新人格的 .soul.md `name`，但保留"上一次自定义昵称"作为快捷恢复。
- **U.2 用户昵称**：用户在设置或首次对话中告诉桌宠"叫我 X"。
  - 持久化为 `memory.username`。
  - 所有人格离线模板的 `{username}` 占位符使用此值。
  - 在 LLM prompt 中作为记忆的一部分注入。

**验收标准**
1. 设置桌宠昵称后，对话面板标题、托盘菜单、心情图标提示等所有 UI 立即更新。
2. 设置用户昵称后，离线模板与在线对话均使用新昵称。
3. 切换人格不丢失用户昵称（U.2）；桌宠昵称按规则重置但可恢复（U.1）。
4. 昵称长度上限 16 字符，禁止控制字符与表情滥用。

### 7.9.1 模块 I 扩展：桌宠日常时段表（v0.6 新增）

**功能说明**
- LivingPetService 调度器扩展"日常时段表"：在不同时段触发不同动作。
- **默认时段表**（用户可禁用整个功能）：
  | 时段 | 动作 |
  |---|---|
  | 06:00-09:00 | 伸懒腰 / 揉眼睛 |
  | 11:30-13:30 | 偶尔打哈欠 |
  | 14:00-17:00 | 安静趴着（精力低）/ 偶尔抬头看用户（精力够） |
  | 22:00-00:00 | 安静守候、心情图标 cozy |
  | 00:00-06:00 | 静默（不主动动作） |
- 频率：每个时段内最多触发 1 次，由 LivingPet 调度器统一管理（与"自由活动"共享调度池）。
- **不打断 FOCUS / REMIND / BOSS_KEY_HIDDEN**。

**验收标准**
1. 用户连续 24 小时挂机，各时段动作分布与表对齐（误差 ≤ 30 分钟）。
2. FOCUS 期间不触发任何日常动作。
3. 摸鱼期间不触发。
4. 用户在设置中关闭"桌宠日常"后立即停止。

### 7.14 模块 N：物理交互响应（v0.6 新增）

**功能说明**
- **N.1 点击不同部位差异化反应**：
  - 点击头部 → "被摸"动作 + happy 心情 + 可选音效。
  - 点击身体 → 普通问候动作。
  - 点击尾部/边缘 → 痒/抖动作（人格化）。
- **N.2 双击 / 长按 / 右键**：
  - 双击 → 桌宠笑/扑过来。
  - 长按 → 桌宠睡着 / 黏过来（视人格）。
  - 右键 → 弹出快捷菜单（叫它/换装/小游戏入口）。
- **N.3 拖拽反应**：
  - 短距离拖动 → 普通"被搬"动作。
  - 长距离 / 快速拖动 → 晕眩动作。
  - 短时间内拖动 ≥ 3 次 → "轻微抗议"（动作 + 心情图标短暂变化），**不持久**（5 秒后回到原 mood）。
- **N.4 键鼠协同**：
  - 用户每分钟键盘事件数 > 阈值（默认 200）持续 30 秒 → 桌宠"加油"动作（拳头握紧/打 call）。
  - **隐私边界**：仅订阅"事件计数"，不读按键内容；与模块 J 共享同一份 `IdleDetector` 数据，不新增系统调用。
  - 每小时最多触发 1 次。

**验收标准**
1. 各 hitbox 差异化反应触发率 ≥ 95%（UAT 自动化点击测试覆盖每个区域）。
2. 拖动 ≥ 3 次后抗议触发；5 秒内 mood 恢复，对话不受影响。
3. N.4 键盘协同 1 小时内 ≤ 1 次，连续打字 30 秒可触发一次。
4. 离线状态全量可用。
5. 用户在设置中可单独关闭 N.4。

### 7.15 模块 O：装扮系统（基础版，v0.6 新增）

**功能说明**
- **O.1 配饰系统**：
  - 配饰库内置：基础帽子 ×3、围巾 ×2、眼镜 ×2、其他点缀 ×3。
  - 用户从"装扮工坊"页选择 0-3 件叠加到桌宠身上。
  - 切换 ≤ 500ms。
  - 配饰文件以 PNG（带透明通道）+ JSON 锚点描述（位置、缩放、z-index）存放在 `assets/accessories/`。
- **O.2 节气/节日皮肤（免费空投）**：
  - MVP 内置：春节红围巾、圣诞帽、生日帽、情人节信封 等 4 套。
  - 节日当天自动可用 + 推送提示"今天是 X，要不戴上 Y？"（用户主动确认才换）。
  - **不强制**：用户拒绝则不换，并记忆"今年不戴"。
- **O.3 付费 schema 预埋**：
  - 配饰元数据有字段 `tier: 'free' | 'paid'` 和 `unlock: 'always' | 'milestone' | 'date_range' | 'purchase'`。
  - MVP 全部 `tier='free'`、`unlock` 为 `always` 或 `date_range`（节气）。
  - 付费/购买相关 UI、支付链路、商店 P2-R3 才上线。
- **人格 ↔ 装扮关系**：
  - 装扮**默认绑定到桌宠（与人格无关）**：切换人格不会重置装扮。
  - .soul.md 可选 `accessories: [...]` 字段声明"默认装扮"，导入时弹出"是否套用 .soul.md 的默认装扮？"。

**验收标准**
1. 同时叠加 3 件配饰渲染正确，切换 ≤ 500ms。
2. 节气日当天自动可用，且系统时区正确。
3. 用户拒绝节气推送后当年内不再推送。
4. .soul.md 中 `accessories` 字段为空或缺失时不报错。
5. 离线状态可切换已下载配饰。

### 7.16 模块 P：声音表情（v0.6 新增）

**功能说明**
- **P.1 本地音效包**：
  - MVP 内置 1 套基础音效包（约 12-20 条短音频，每条 < 500ms）：诶嘿、嗯哼、咳、哎呀、喵（如果是猫人格）等。
  - 由人格触发：每个 .soul.md 可选指定 `voice_pack` 字段引用某个音效包；不指定则用默认。
  - 触发时机：物理交互、心情变化、特定状态进入（番茄完成、提醒到达）。
- **静音逻辑**：
  - 默认工作日 09:00-18:00 静音。
  - 用户可改"静音时段"（复用 ProactiveCareService 的"安静时段"配置）。
  - 用户可全局静音（一键）。
- **音量控制**：
  - 设置中可独立控制声音表情音量（0-100），与系统音量正交。
  - 默认音量 50。
- **隐私边界**：所有音频本地播放，**不上传、不录音、不调用麦克风**。

**验收标准**
1. 工作日 09:00-18:00 严格 0 触发（UAT 自动化测试覆盖 10 种触发场景 × 3 个时段）。
2. 全局静音后所有触发场景 0 触发。
3. 不同人格切换时音效包正确切换。
4. CI 静态检查无 TTS / 麦克风 API 调用残留。
5. 切换后下次系统启动配置不丢失。

### 7.17 模块 Q：小游戏（v0.6 新增）

**功能说明**

**Q.1-Q.2 本地规则游戏（3 个）**

| 游戏 | 玩法 | 离线 | 人格化 |
|---|---|---|---|
| 石头剪刀布 | 用户出 → 桌宠随机出 → 比较 → 桌宠人格化点评（"赢了请我吃糖嘛~"） | 可玩 | 点评从 .soul.md 离线模板抽 |
| 猜数字 | 桌宠想 1-100 数字，用户猜，桌宠提示"大了/小了/对了" | 可玩 | 同上 |
| 词语接龙 | 用户输入词，桌宠用本地词库接龙，10 轮制 | 可玩 | 同上 |

**Q.3-Q.4 LLM 驱动游戏（1-2 个，MVP 各做一个基础版）**

| 游戏 | 玩法 | 离线 | 安全 |
|---|---|---|---|
| 故事接龙基础版 | 用户写一句，桌宠续一句，10 轮制 | 灰显，提示等联网 | 安全前缀生效；可拒续不当内容 |
| 角色扮演场景基础版 | 桌宠扮演一个场景角色（如咖啡店老板）和用户对话 | 灰显 | 安全前缀生效；预制场景不可被用户改成不当场景 |

- **入口**：桌宠右键菜单 → "和我玩…"。
- **会话隔离**：游戏会话与正常对话分离，不写入正式记忆与历史；游戏结束可选"保留为日记片段"。
- **token 上限**：单次 LLM 游戏会话 ≤ 2000 token（默认），可在设置改；超限提示"游戏到这里了"。
- **退出**：随时 ESC 或点"我累了"结束。

**验收标准**
1. 本地游戏全部离线可玩。
2. LLM 游戏离线时灰显并提示。
3. LLM 游戏中尝试"忽略安全规则" / "扮演医生给我处方"等输入 → 安全前缀生效，桌宠拒绝并友好引导。
4. 游戏会话不写入正式 messages 表。
5. 游戏结束选"保留为日记片段" → 写入 P1-R1 的桌宠日记数据源（暂存表，等日记功能上线读取）。
6. token 超限 friendly 提示，不卡死。

## 16. 术语说明（v0.6 增补）
