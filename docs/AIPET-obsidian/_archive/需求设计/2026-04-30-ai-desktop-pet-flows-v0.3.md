# AI桌宠 流程与状态机（v0.3）

- 文档版本：v0.3
- 日期：2026-04-30
- 说明：本文件定义 P0 关键流程和状态切换，作为前后端实现依据。

## 1. 首次启动流程

1. 应用启动。
2. 检查本地配置是否存在。
3. 若不存在，进入“隐私同意页”。
4. 用户同意后创建默认配置与本地库。
5. 进入桌宠主态并展示引导。

失败分支：
1. 本地库初始化失败：提示重试并记录错误日志。
2. 用户拒绝隐私同意：应用退出，仅保留再次启动入口。

## 2. 快捷唤起对话流程

1. 监听全局快捷键。
2. 命中后弹出对话面板并聚焦输入框。
3. 用户发送消息。
4. 判断网络状态。
5. 在线：云模型回复；离线：规则回复。
6. 写入消息记录并刷新会话视图。

失败分支：
1. 快捷键冲突：提示用户在设置中改键。
2. 云调用超时：自动降级为离线规则提示。

## 3. 提醒闭环流程

1. 用户创建提醒（一次性/重复）。
2. 到点触发通知与桌宠动作。
3. 用户选择：完成/稍后/忽略。
4. 若稍后：snooze_count +1，延迟10分钟再触发。
5. snooze_count > 3：标记“未完成待复盘”。
6. 写入提醒历史与埋点。

## 4. 番茄钟流程

1. 用户启动番茄钟。
2. 进入专注态，倒计时开始。
3. 可暂停或提前结束。
4. 到点进入休息态并通知。
5. 完成一次记录统计。

## 5. 网络状态切换流程

1. 监听网络状态变化。
2. 在线->离线：显示横幅“离线规则模式”，切换对话策略。
3. 离线->在线：自动恢复云回复，触发离线埋点补发。
4. 若补发失败：重试队列保留至下次联网。

## 6. 核心状态机（简化）

### 6.1 桌宠状态

- `IDLE`：空闲
- `FOCUS`：专注
- `REMIND`：提醒
- `REST`：休息

状态迁移：
1. `IDLE -> FOCUS`：番茄钟开始。
2. `FOCUS -> REST`：专注计时完成。
3. `* -> REMIND`：提醒触发。
4. `REMIND -> IDLE`：提醒处理完毕。
5. `REST -> IDLE`：休息结束或手动跳过。

### 6.2 对话模式状态

- `ONLINE_CHAT`
- `OFFLINE_RULE`

迁移：
1. 有网：`ONLINE_CHAT`。
2. 断网/云超时：`OFFLINE_RULE`。
3. 网络恢复：回到 `ONLINE_CHAT`。
