## 1. 背景与目标

AI桌宠项目目标是构建一个常驻桌面的智能伙伴，兼顾"陪伴感"与"执行力"。

基于竞品调研，当前市场存在三类明显缺口：
1. 纯陪伴产品可爱但低任务完成率，留存弱。
2. 纯效率助手可用但缺少人格和长期使用粘性。
3. 头部陪伴产品（Replika / Character.AI / Nomi）人格中心化，**用户无法对人格做实质性塑造与所有权占有**。

MVP 的核心命题：**用"用户自主人格 + 主动陪伴感 + 轻任务闭环"三者的组合**，证明：
1. 桌宠形态 + 用户自主人格能显著提升日活留存与情感粘性。
2. **主动关心（而非被动等待问答）是陪伴产品的护城河**。
3. 轻任务闭环把陪伴感转化为留存指标。
4. 满足离线可用上线要求。

## 2. 已确认产品决策（冻结）

1. 首发平台：仅 Windows（Windows 10/11，64-bit）。
2. 价值权重：陪伴:效率 = 6:4；陪伴权重通过"用户自主人格 + 主动关心"显式承载。
3. 截图问答：保持 P1，不纳入本期 P0 范围。
4. 离线可用：作为上线硬约束。
5. 首发技术栈：Tauri 2.x（Rust 主进程 + WebView 前端）。
6. 桌宠形态：2D 桌宠。资源管线见 §15。
7. 离线对话策略：规则回复 + 人格化模板（本地小模型 P1-R3 探索）。
8. 提醒稍后策略：有限稍后（最多 3 次）。
9. 数据保留默认：对话默认保留 90 天。
10. 敏感权限默认：截图/剪贴板默认关闭，首次使用逐项授权。
11. **人格自主权**：用户可创建、编辑、导入、导出、切换桌宠人格，人格文件为 Markdown 格式（`*.soul.md`），完全归属用户。
12. **快捷键默认**：唤起对话 `Ctrl + Alt + Space`；摸鱼模式 `Ctrl + Shift + B`；用户均可自定义。
13. **主动关心频率上限（v0.5 新增）**：每 2 小时最多 1 次，每日最多 4 次；用户可全局关闭、可调"安静时段"。
14. **生命感非养成原则（v0.5 新增）**：桌宠"生理状态"仅作展示，不引入需要用户喂养、签到、肝度的负担机制；用户离开几天回来后桌宠不会"死"或"变弱"。
15. **隐私页人格化（v0.5 新增）**：首次启动的隐私同意页由"宣誓人格"用第一人称叙述，覆盖原数据策略要点。

## 3. 产品定位

一句话定位：**`一个由你亲手塑造、会主动关心你、陪你把小事做完的 AI 桌宠`**。

差异点（相对竞品）：
1. 相对 Replika / Character.AI：**人格归属用户**，可编辑、导出、迁移，不被平台锁定。
2. 相对 Clawster / PetClaw：**主动关心**而非纯被动问答，桌宠"在那里"被感知，而不是隐藏在快捷键后。
3. 相对 Microsoft Copilot：保留"非工具感"的伙伴关系，不以系统级强势入侵替代用户操作。

核心价值主张：
1. **陪伴（60%）**：常驻、有生命感、主动关心、人格由你定义。
2. **效率（40%）**：提醒、待办、番茄钟、快捷问答、文件交互形成闭环。
3. **可控**：记忆和隐私可视、可关、可删；人格可编辑、可导出。

## 4. 目标用户与核心场景

### 4.1 目标用户

1. 学生用户：需要轻量督学、番茄钟、复盘提醒。
2. 办公人群：需要碎片化任务管理和快速信息处理。
3. 独立开发者 / 创作者：需要低打断成本的桌面助手。
4. 二次元 / 角色爱好者：愿意花时间塑造自己的桌宠形象与人格。

### 4.2 核心场景

1. 快速问答：全局快捷键唤起对话。
2. 提醒执行：喝水/休息/日程提醒。
3. 专注流程：番茄钟驱动专注与休息节奏。
4. 轻任务拆解：自然语言目标转待办清单。
5. 个性化互动：桌宠记忆称呼与偏好。
6. 人格塑造：在"人格工坊"塑造桌宠人设。
7. **主动陪伴（v0.5 新增）**：长时间未操作时被关心；深夜还在工作被温和提醒。
8. **文件交互（v0.5 新增）**：拖文件到桌宠身上得到总结/重命名/解释。
9. **摸鱼模式（v0.5 新增）**：领导路过一键隐藏。

## 5. MVP范围定义

### 5.1 必做（P0，M1-M4 内）

1. 桌宠常驻与基础互动。
2. 文本对话与全局快捷唤起。
3. 提醒系统（定时提醒、重复提醒、完成/稍后）。
4. 番茄钟（专注/休息）。
5. 轻量待办（创建、完成、延期）。
6. 基础记忆（称呼、偏好、作息）。
7. 设置中心（模型、提醒、隐私开关）。
8. 本地数据存储与导出/删除。
9. 离线模式（无网络时核心能力可用）。
10. 人格系统 P0 子集：内置 3 个默认人格、GUI 编辑、切换、.soul.md 导入导出、试聊沙盒。
11. 首次启动 Onboarding（6 步）。
12. 自动更新（tauri-updater）。
13. **桌宠生命感（模块 I）**：自由活动、心情图标、生理节律展示。
14. **情境感知关心（模块 J）**：键鼠空闲检测、时间感知主动关心、跨日纪念日。
15. **摸鱼模式（模块 K）**：老板键一键隐藏。
16. **文件拖入交互（模块 L）**：拖文本文件到桌宠 → 总结 / 解释 / 重命名建议。
17. **隐私页人格化（模块 M）**：首启同意页由人格用第一人称叙述。

### 5.2 可选（P1，分轮次）

#### P1-Round 1：情感深化（M5-M6）
1. **AI 辅助人格创作**：在工坊"我想要一个像 X 的桌宠" → 生成 .soul.md 草稿。
2. **桌宠日记**：基于互动每日 1-3 句话自动写日记，用户可翻阅。
3. **上下文锚定对话**：对话框 `@剪贴板` `@文件` 注入上下文（包含原 P1 截图问答）。
4. **图片拖入**：模块 L 扩展支持图片（OCR + 视觉理解）。

#### P1-Round 2：效率深化（M7-M8）
5. **专注复盘自动化**：番茄结束时按前台应用名（不读内容）回顾"刚刚 25 分钟主要在 X"。
6. **习惯追踪**：基于提醒历史的连续打卡可视化。
7. **多人格情境切换**：按时间 / 前台应用自动切换人格。
8. **私聊模式**：本次会话不写历史不更新记忆。
9. **多宠物皮肤 / 形象资源包**。
10. **云端同步基础**（账号体系预埋，不开放）。

#### P1-Round 3：生态扩展（M9+，POST-MVP 探索）
11. **MCP 技能装载**：人格 .soul.md 的 `# 集成` 区段声明 MCP 服务，用户授权后启用。
12. **人格 fork / 血脉链**：基于他人 .soul.md 修改时记录 `forked_from`。
13. **人格成长 / 学习**：观察互动后建议调整 tone_profile，用户授权才生效。
14. **本地 HTTP / MCP API**：暴露本地 API 给 Raycast / Alfred 等工具。
15. **本地小模型对话**：Phi-3.5-mini Q4 或同级，作为离线生成回复来源。
16. **人格市场**（社区分享 .soul.md）。

### 5.3 明确不做（本阶段）

1. 复杂 3D 实时渲染。
2. 开放式 UGC 角色市场服务端。
3. 多人社交空间。
4. 深度系统自动化（批量控制应用、文件自动改写）。**注**：MCP 技能装载（P1-R3）由用户授权启用，不属于此条范围。
5. 语音播报与语音输入（评估为 P2）。
6. 桌宠"喂养 / 死亡 / 弃养"等负担机制。

## 7. 功能需求（P0）

### 7.1-7.7（沿用 v0.4）

7.1 模块A：桌宠壳层与基础交互。
7.2 模块B：对话与唤起（默认 `Ctrl+Alt+Space`，首 token p50 ≤ 1.5s）。
7.3 模块C：提醒系统（含软/硬提醒并发优先级）。
7.4 模块D：番茄钟（含暂停/恢复/休眠校准）。
7.5 模块E：轻量待办（含 AI 拆解）。
7.6 模块F：记忆与偏好（与人格正交）。
7.7 模块G：设置与隐私控制（API Key DPAPI 加密）。

> 详细验收沿用 v0.4 §7.1-7.7。

### 7.8 模块H：人格系统（沿用 v0.4）

3 个内置人格、GUI 简易/进阶 Markdown 模式、试聊沙盒、.soul.md 导入导出、安全护栏不可覆盖。详见《角色与人格设计 v0.1》。

### 7.9 模块 I：桌宠生命感（v0.5 新增）

**功能说明**
- **I.1 自由活动**：桌宠在 IDLE 状态下偶尔小幅"逛桌面"。
  - 频率：每 5-15 分钟随机一次，每次 5-15 秒，移动距离不超过屏幕宽度 5%。
  - 路径不规则但不夸张（不影响用户工作）。
  - 多屏幕情况下不跨屏漫游（除非用户拖动）。
- **I.2 心情图标**：桌宠头顶可显示一个轻量心情符（emoji/小图标）。
  - 状态枚举：`happy / neutral / sleepy / focused / cozy`。
  - 由"互动密度 + 时间 + 当前状态机"驱动。
  - 用户可在设置中关闭。
- **I.3 生理节律展示**（非养成）：
  - 桌宠精力值（0-100）：长时间无互动会"打瞌睡"（视觉表现：闭眼 / 蹲下 / sleepy 图标）。
  - 用户回来交互即恢复，**不需要"喂养"**。
  - 不存在"饿死"/"流失"机制。
  - 用户可全局关闭"生理节律"。

**验收标准**
1. 自由活动每次位移 ≤ 屏幕宽度 5%，不遮挡键鼠操作焦点。
2. 心情图标变化的总频率 ≤ 每 10 分钟一次（避免视觉骚扰）。
3. 用户连续离开 3 天后回来打开应用，桌宠不会处于异常态（无"流失")。
4. 生命感全部模块都可在设置中独立开关。
5. 自由活动不在 FOCUS 状态下触发。

### 7.10 模块 J：情境感知关心（v0.5 新增）

**功能说明**
- **J.1 键鼠空闲检测**：用户连续 N 分钟无键鼠操作（默认 90 分钟，可配置）→ 桌宠用一句话关心，使用当前人格的"# 离线模板 / ## 共情" 池。
- **J.2 时间感知**：
  - 23:00 后键盘活动持续 30 分钟以上 → 温和提醒（"还在写啊？要不留点给明天"）。
  - 长时间未启动番茄钟 + 高频任务切换 → 推荐试一次番茄。
- **J.3 跨日纪念日**：
  - 首次启动满 7 天 / 30 天 / 100 天等节点 → 桌宠主动说一句应景的话。
  - 连续打卡某项提醒满 N 天 → 桌宠庆祝。
- **频率限制**：所有主动关心总和每 2 小时 ≤ 1 次，每日 ≤ 4 次。
- **安静时段**：用户可设置"勿扰时段"（如 14:00-16:00 工作期间不主动）。
- **隐私边界**：仅基于"键鼠是否空闲 + 系统时间"，**不读应用名、不读窗口标题、不读输入内容**。

**验收标准**
1. 频率上限严格生效，UAT 中 24 小时观测不超过 4 次。
2. 安静时段内不触发任何主动关心。
3. 用户在设置中关闭模块 J 后，所有主动关心立即停止。
4. 离线状态下基于本地规则与人格模板照常工作。
5. 关心内容由当前人格的离线模板池随机抽取，不调用 LLM（节省 token + 离线一致）。

### 7.11 模块 K：摸鱼模式（v0.5 新增）

**功能说明**
- 默认快捷键 `Ctrl + Shift + B`（用户可改）。
- 一键执行：桌宠 + 对话面板 + 工坊 + 设置窗口全部隐藏；托盘图标变更为"摸鱼模式中"。
- 再次按下 → 恢复全部窗口到上次状态。
- 隐藏期间所有提醒延后到恢复，番茄钟继续计时（不打断）。

**验收标准**
1. 隐藏 / 恢复响应时间 < 200ms。
2. 隐藏期间触发的硬提醒不弹出（延后到恢复时合并提示）。
3. 摸鱼期间 NetworkProbe / Scheduler 不停止，恢复后状态正确。
4. 快捷键冲突可探测并提示改键。

### 7.12 模块 L：文件拖入交互（v0.5 新增）

**功能说明**
- 用户从资源管理器把文件拖到桌宠身上 → 桌宠展开 3 个动作泡泡：**总结 / 解释 / 重命名建议**。
- 用户点击其中一个 → 直接发起对话，文件内容作为上下文。
- P0 支持文本类（.txt / .md / .pdf 提取文本）。
- 图片支持移到 P1-R1（需要视觉模型，部分用户的 LLM Provider 不支持）。
- 大文件保护：> 5MB 文本 → 提示"文件较大，是否继续（可能消耗较多 token）"。

**验收标准**
1. 拖入后桌宠 3 秒内显示动作泡泡。
2. 不支持的文件类型给可读错误提示，不崩溃。
3. 拖入后不自动发送，必须用户点击动作。
4. 离线时拖入显示"重命名建议（规则）"作为唯一可用动作；其他动作灰显并提示。
5. 文件内容**不写入对话历史长期存储**（避免污染记忆与膨胀 db），仅当次会话上下文。

### 7.13 模块 M：隐私页人格化（"灵魂宣誓"）（v0.5 新增）

**功能说明**
- 替换 Onboarding Step 1 的隐私同意页。
- 由内置"宣誓人格"（默默 momo）用第一人称叙述：
  > "在我们开始之前，我想说几句。
  > 我的记忆只在你电脑里。你随时可以让我忘掉一切。
  > 当我们要联网聊天时，我会先告诉你；如果你不想，我们就只用本地能力。
  > 截图、剪贴板这些权限，默认是关的。需要时再开。
  > 这些不是法务条款，是我的承诺。点'我懂了'就一起开始。"
- 同步右侧或下方提供"查看完整数据策略"链接，展开正式版法务文本。

**验收标准**
1. 信息完整性等价于原冷文本（数据本地、可清除、网络透明、权限默认关）。
2. 可一键展开正式版条款。
3. 用户拒绝后正常退出（同 v0.4 流程）。
4. 内容文案在 M0 决策周内由产品 + 法务双签字定版。
5. 不损失原同意行为的法律有效性（"我懂了"按钮等价于"同意"）。

## 8. 数据与隐私规范（v0.5 增量）

### 8.1 数据分类（新增）

1. 配置数据：快捷键、主题、开关项。
2. 对话数据：消息文本、时间戳、模式、当时人格 ID、`is_private` 标记（P1-R2）。
3. 记忆数据。
4. 任务数据。

## 14. 实施优先级判断逻辑（v0.5 新增）

### 14.1 P0 入选标准（要求三选二满足）
1. **强化定位差异化**：直接服务于"用户自主人格"或"主动陪伴"。
2. **成本低**：M1-M4 内可在不显著扩 schema / 不引入新进程的前提下实现。
3. **首启即可见**：用户在前 7 天就能感知，影响 D7 留存。

### 14.2 P1-R1 入选标准
1. 服务于情感深化（不直接增加效率，但增加情感粘性）。
2. 依赖 MVP 的稳定数据积累（如桌宠日记需要互动历史）。

### 14.3 P1-R2 入选标准
1. 服务于效率深化。
2. 需要权限设计或较多 UX 打磨（如专注复盘的应用名读取）。

### 14.4 P2-R3 入选标准
1. 需要架构层准备（如 MCP / 本地 API 需要 IPC 抽象稳定）。
2. 需要社区/生态发酵（如人格市场、fork 链）。
3. 有违反"人格稳定"等核心原则的风险，需要充分讨论（如人格成长）。

## 16. 术语说明（v0.5 增补）

1. **MVP**：最小可行产品。
2. **轻任务闭环**：任务从创建、提醒到完成形成完整流程。
3. **规则回复**：离线时基于命令词和模板返回，不调用生成模型。
4. **人格 / Soul**：定义桌宠"是谁、怎么说话、能做什么"的可编辑文件 `*.soul.md`。
5. **记忆**：用户授权下保存的偏好与习惯数据。
6. **安全护栏**：所有人格不可绕过的全局安全规则前缀。
7. **硬提醒 / 软提醒**：能否打断专注态的提醒分级。
8. **生命感（Living Pet）（v0.5）**：让桌宠"被感知存在"的视觉/行为机制集合，不引入养成负担。
9. **主动关心（Proactive Care）（v0.5）**：基于本地规则触发的、不依赖用户问的关心消息。
10. **灵魂宣誓（Soul Pledge）（v0.5）**：首启隐私同意页的人格化叙述。
11. **R1 / R2 / R3（v0.5）**：MVP 后的三个交付轮次（情感 / 效率 / 生态）。
