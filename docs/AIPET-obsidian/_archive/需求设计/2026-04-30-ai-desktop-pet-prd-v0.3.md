## 1. 背景与目标

AI桌宠项目目标是构建一个常驻桌面的智能伙伴，兼顾“陪伴感”和“执行力”。

基于竞品调研，当前市场存在两类明显缺口：
1. 纯陪伴产品可爱但低任务完成率，留存弱。
2. 纯效率助手可用但缺少人格和长期使用粘性。

MVP阶段目标：在仅 Windows 平台先完成一个可验证的产品闭环，证明“桌宠形态能显著提升轻任务执行率与日活留存”，并满足离线可用上线要求。

## 2. 已确认产品决策（冻结）

1. 首发平台：仅 Windows（Windows 10/11）。
2. 价值权重：陪伴:效率 = 6:4。
3. 截图问答：保持 P1，不纳入本期 P0 范围。
4. 离线可用：作为上线硬约束。
5. 首发技术栈：Tauri（桌面容器）。
6. 桌宠形态：2D 桌宠。
7. 离线对话策略：规则回复（非本地生成模型）。
8. 提醒稍后策略：有限稍后（最多 3 次）。
9. 数据保留默认：对话默认保留 90 天。
10. 敏感权限默认：截图/剪贴板默认关闭，首次使用逐项授权。

## 3. 产品定位

一句话定位：`一个会陪你把小事做完的 AI 桌宠`。

核心价值主张：
1. 陪伴（60%）：常驻、可互动、有稳定人格。
2. 效率（40%）：提醒、待办、番茄钟、快捷问答形成闭环。
3. 可控：记忆和隐私可视、可关、可删。

## 4. 目标用户与核心场景

### 4.1 目标用户

1. 学生用户：需要轻量督学、番茄钟、复盘提醒。
2. 办公人群：需要碎片化任务管理和快速信息处理。
3. 独立开发者/创作者：需要低打断成本的桌面助手。

### 4.2 核心场景

1. 快速问答：全局快捷键唤起对话，不切换主应用。
2. 提醒执行：喝水/休息/日程提醒，支持完成或稍后。
3. 专注流程：番茄钟驱动专注与休息节奏。
4. 轻任务拆解：自然语言目标转待办清单。
5. 个性化互动：桌宠记忆称呼与偏好。

## 5. MVP范围定义

### 5.1 必做（P0）

1. 桌宠常驻与基础互动。
2. 文本对话与全局快捷唤起。
3. 提醒系统（定时提醒、重复提醒、完成/稍后）。
4. 番茄钟（专注/休息）。
5. 轻量待办（创建、完成、延期）。
6. 基础记忆（称呼、偏好、作息）。
7. 设置中心（模型、提醒、隐私开关）。
8. 本地数据存储与导出/删除。
9. 离线模式（无网络时核心能力可用）。

### 5.2 可选（P1）

1. 截图问答。
2. 剪贴板总结。
3. 多宠物皮肤。
4. 云端同步。

### 5.3 明确不做（本阶段）

1. 复杂3D实时渲染。
2. 开放式UGC角色市场。
3. 多人社交空间。
4. 深度系统自动化（批量控制应用、文件自动改写）。

## 6. 离线能力矩阵（上线门槛）

| 模块 | 在线状态 | 离线状态 | 恢复联网后 |
|---|---|---|---|
| 桌宠壳层 | 全量可用 | 全量可用 | 无需补偿 |
| 对话 | 云模型回复 | 规则回复（命令词/关键词/通用提示） | 自动切回在线回复 |
| 提醒 | 全量可用 | 全量可用 | 同步离线触发记录 |
| 番茄钟 | 全量可用 | 全量可用 | 同步统计 |
| 待办 | 全量可用 | 全量可用 | 合并离线改动 |
| 记忆 | 全量可用 | 全量可用 | 无冲突时直接合并 |
| 设置/隐私 | 全量可用 | 全量可用 | 无需补偿 |
| 埋点 | 实时上报 | 本地缓存 | 联网后补发 |

离线对话规则回复优先级：
1. 功能命令词（如“新增提醒”“开始番茄钟”）。
2. 关键词模板（如“总结”“翻译”返回离线能力提示）。
3. 通用离线提示（引导联网或执行本地功能）。

## 7. 功能需求（P0）

### 7.1 模块A：桌宠壳层与基础交互

功能说明：
- 桌宠常驻桌面，可拖动，支持置顶开关。
- 支持空闲、专注、提醒、休息四种状态动作。

验收标准：
1. 启动后 5 秒内可见桌宠。
2. 可启用/禁用始终置顶。
3. 最小化后可从托盘恢复。

### 7.2 模块B：对话与唤起

功能说明：
- 全局快捷键唤起对话框，默认 `Alt + Space`（可改）。
- 在线支持连续上下文对话。
- 离线切换为规则回复，不崩溃。

验收标准：
1. 联网首次响应目标 < 3 秒。
2. 本地保留最近 20 条会话。
3. 离线时必须明确显示“离线规则模式”。

### 7.3 模块C：提醒系统

功能说明：
- 支持一次性提醒、每日重复提醒。
- 提醒动作：完成、稍后 10 分钟、忽略。
- 稍后上限：3 次；第 4 次触发时转“未完成待复盘”。

验收标准：
1. 触发误差 <= 30 秒。
2. 重复提醒可开关。
3. 离线状态照常触发。
4. 全量行为写入提醒历史。

### 7.4 模块D：番茄钟

功能说明：
- 默认 25/5 模板，可自定义时长。
- 专注结束触发状态变化与提醒。

验收标准：
1. 支持开始、暂停、结束。
2. 统计当日完成番茄数。
3. 离线状态完整可用。

### 7.5 模块E：轻量待办

功能说明：
- 创建、完成、延期。
- AI可拆解目标为 3-7 个子任务（在线）。

验收标准：
1. 字段包含标题、截止时间、状态、来源。
2. AI拆解结果可编辑再保存。
3. 离线可新增、编辑、完成。

### 7.6 模块F：记忆与偏好

功能说明：
- 存储称呼、作息、提醒习惯。
- 支持查看、编辑、单条删除、清空。

验收标准：
1. 所有记忆项可视化管理。
2. 清空后对话不再使用旧偏好。
3. 离线读写一致。

### 7.7 模块G：设置与隐私控制

功能说明：
- 模型配置（API Key、模型名）。
- 隐私开关（保存对话、启用记忆）。
- 数据操作（导出、导入、删除全部）。

验收标准：
1. 首次启动展示隐私说明并同意。
2. 权限页可见截图/剪贴板授权状态。
3. 导出文件可用于同版本导入恢复。

## 8. 数据与隐私规范

### 8.1 数据分类

1. 配置数据：快捷键、主题、开关项。
2. 对话数据：消息文本、时间戳、模式（在线/离线规则）。
3. 记忆数据：偏好键值与更新时间。
4. 任务数据：提醒、待办、番茄统计。
5. 运行数据：错误日志、埋点缓存。

### 8.2 存储与保留

1. 默认本地存储（SQLite + 本地文件）。
2. 对话默认保留 90 天，超期自动清理。
3. 记忆/任务默认长期保留，用户可随时清空。
4. API Key 本地加密存储。

### 8.3 删除与导出

1. 提供一键删除全部用户数据。
2. 删除执行完成后本地不可恢复。
3. 提供JSON导出与导入（同版本兼容）。

## 9. 内容安全与边界

1. 高风险内容（自伤、暴力、违法）不提供指导性细节。
2. 医疗/法律/金融类问题提供“非专业建议”提示并引导专业渠道。
3. 对未成年人语境采用保守响应：不强化情感依赖，不提供危险建议。
4. 离线规则回复同样遵守安全模板。

## 10. 非功能需求

### 10.1 性能

1. 冷启动 <= 5 秒（普通办公机）。
2. 常驻内存目标 <= 500MB（不含外部模型进程）。
3. 常态 CPU 占用平均 <= 5%。

### 10.2 稳定性

1. 单日运行崩溃率 < 1%。
2. 提醒、待办、番茄钟可在异常后恢复。

### 10.3 可观测性

1. 核心行为具备埋点。
2. 离线事件本地缓存并补发。
3. 错误日志支持本地导出用于排障。

## 11. 关键指标（MVP验收）

1. D1 留存 >= 35%。
2. D7 留存 >= 15%。
3. 人均日提醒完成次数 >= 2。
4. 番茄钟启动率 >= 25%。
5. 日均主动唤起次数 >= 3。
6. 崩溃率 < 1%。

## 12. 版本计划与退出条件

1. M1（第1-2周）：桌宠壳层、唤起对话、设置基础。
   - 退出条件：核心UI可跑通，快捷键稳定，崩溃率 < 3%。
2. M2（第3-4周）：提醒、番茄钟、待办闭环。
   - 退出条件：三大模块离线可用，主流程UAT通过率 >= 90%。
3. M3（第5-6周）：记忆、隐私治理、离线规则回复完善。
   - 退出条件：权限与数据策略全部可验证，安全模板覆盖高风险输入。
4. M4（第7-8周）：优化、灰度内测、埋点验收。
   - 退出条件：满足性能指标，埋点完整率 >= 95%，可发布候选版。

## 13. 开放项（实现前需确认）

1. 默认提醒模板集合（喝水/久坐/学习）文案版本。
2. 2D桌宠动作资源的制作与交付规格。
3. 是否在MVP内置本地语音播报（当前默认不做）。

## 14. 术语说明

1. MVP：最小可行产品，目标是验证核心价值。
2. 轻任务闭环：任务从创建、提醒到完成形成完整流程。
3. 规则回复：离线时基于命令词和模板返回，不调用生成模型。
