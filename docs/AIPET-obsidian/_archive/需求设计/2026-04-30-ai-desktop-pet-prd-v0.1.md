# AI桌宠 需求文档（PRD v0.2）

- 文档版本：v0.2
- 创建日期：2026-04-30
- 适用阶段：MVP定义阶段
- 关联文档：`docs/2026-04-30-ai-desktop-pet-competitor-research.md`

## 1. 背景与目标

AI桌宠项目目标是构建一个常驻桌面的智能伙伴，兼顾“陪伴感”和“执行力”。

基于竞品调研，当前市场存在两类明显缺口：
1. 纯陪伴产品可爱但低任务完成率，留存弱。
2. 纯效率助手可用但缺少人格和长期使用粘性。

MVP阶段目标：在仅 Windows 平台先完成一个可验证的产品闭环，证明“桌宠形态能显著提升轻任务执行率与日活留存”，并满足离线可用上线要求。

## 2. 产品定位

一句话定位：`一个会陪你把小事做完的 AI 桌宠`。

核心价值主张：
1. 陪伴（60%）：常驻、可互动、有稳定人格。
2. 效率（40%）：把提醒、待办、番茄钟、快问快答做成闭环。
3. 可控：记忆和隐私可视、可关、可删。

## 3. 目标用户与场景

### 3.1 目标用户

1. 学生用户：需要轻量督学、番茄钟、复盘提醒。
2. 办公人群：需要碎片化任务管理和快速信息处理。
3. 独立开发者/创作者：需要低打断成本的桌面助手。

### 3.2 核心使用场景

1. 快速问答：用户在任意应用中通过快捷键唤起问答。
2. 提醒执行：用户设置喝水、休息、日程提醒并完成打卡。
3. 专注流程：用户启动番茄钟，桌宠在专注与休息阶段给出状态反馈。
4. 轻任务拆解：用户输入“今天要做什么”，系统生成可执行待办清单。
5. 个性化互动：桌宠记住称呼、作息偏好，并用于后续互动。

## 4. MVP范围定义

### 4.1 必做（P0）

1. 桌宠常驻与基础互动。
2. 文本对话与全局快捷唤起。
3. 提醒系统（定时提醒、重复提醒、完成/稍后）。
4. 番茄钟（专注/休息）。
5. 轻量待办（创建、完成、延期）。
6. 基础记忆（称呼、偏好、作息）。
7. 设置中心（模型、提醒、隐私开关）。
8. 本地数据存储与导出/删除。
9. 离线模式（无网络时核心能力可用）。

### 4.2 可选（P1）

1. 截图问答。
2. 剪贴板总结。
3. 多宠物皮肤。
4. 云端同步。

### 4.3 明确不做（本阶段）

1. 复杂3D实时渲染。
2. 开放式UGC角色市场。
3. 多人社交空间。
4. 深度系统自动化（批量控制应用、文件自动改写）。

## 5. 功能需求

### 5.1 模块A：桌宠壳层与基础交互

功能说明：
- 桌宠常驻桌面，可拖动，支持置顶开关。
- 支持空闲、专注、提醒、休息四种状态动作。

用户故事：
1. 作为用户，我希望桌宠不遮挡核心工作区域，并可一键隐藏。
2. 作为用户，我希望桌宠状态能反馈我当前节奏（专注/休息）。

验收标准：
1. 启动后 5 秒内可见桌宠。
2. 可在设置中启用/禁用“始终置顶”。
3. 最小化后可从系统托盘恢复。

### 5.2 模块B：对话与唤起

功能说明：
- 全局快捷键唤起对话框。
- 支持连续上下文对话（单会话）。
- 离线状态提供本地模型或离线降级提示。

用户故事：
1. 作为用户，我希望在不切换主应用时快速提问。
2. 作为用户，我希望最近几轮对话可回看。

验收标准：
1. 快捷键默认 `Alt + Space`（可自定义）。
2. 联网情况下，首次响应时间目标 < 3 秒。
3. 保留最近 20 条本地会话记录。
4. 离线情况下，对话不崩溃，明确提示当前模式或调用本地模型。

### 5.3 模块C：提醒系统

功能说明：
- 支持一次性提醒、每日重复提醒。
- 提醒动作：完成、稍后 10 分钟、忽略。

用户故事：
1. 作为用户，我希望桌宠准时提醒我喝水和休息。
2. 作为用户，我希望无法立即处理时可稍后再提醒。

验收标准：
1. 提醒触发时间误差 <= 30 秒。
2. 每个提醒支持开启/关闭重复。
3. 提醒结果写入历史记录。
4. 离线状态下提醒照常触发。

### 5.4 模块D：番茄钟

功能说明：
- 提供默认 25/5 分钟专注模板。
- 支持自定义专注时长和休息时长。

用户故事：
1. 作为用户，我希望通过桌宠进入专注节奏。
2. 作为用户，我希望查看当天专注次数。

验收标准：
1. 可开始、暂停、结束番茄钟。
2. 专注结束时触发桌宠状态变化与提醒。
3. 统计当日完成番茄数。

### 5.5 模块E：轻量待办

功能说明：
- 创建待办、标记完成、延期到指定时间。
- 可由AI将自然语言目标拆解为 3-7 个子任务。

用户故事：
1. 作为用户，我希望一句话生成当天待办。
2. 作为用户，我希望完成后有明确反馈。

验收标准：
1. 待办支持标题、截止时间、状态字段。
2. AI拆解结果可编辑后再保存。
3. 完成项可筛选查看。
4. 离线状态可新增、编辑、完成待办。

### 5.6 模块F：记忆与偏好

功能说明：
- 仅存储基础偏好：称呼、作息、提醒习惯。
- 在设置中可查看、编辑、删除。

用户故事：
1. 作为用户，我希望桌宠记住我怎么称呼。
2. 作为用户，我希望随时清空个人记忆。

验收标准：
1. 记忆项均可单条删除。
2. 提供“一键清空记忆”。
3. 清空后对话中不再使用旧偏好。

### 5.7 模块G：设置与隐私控制

功能说明：
- 模型供应商配置（API Key、模型名）。
- 隐私选项：是否保存对话、是否启用记忆。
- 数据操作：导出本地数据、删除全部数据。

用户故事：
1. 作为用户，我希望知道哪些数据被保存。
2. 作为用户，我希望可以导出并迁移我的数据。

验收标准：
1. 首次启动展示隐私说明与同意项。
2. 所有隐私开关默认可见。
3. 导出文件可被再次导入（至少支持同版本）。

## 6. 非功能需求

### 6.1 性能

1. 应用冷启动 <= 5 秒（普通办公机）。
2. 常驻内存目标 <= 500MB（不含外部模型进程）。
3. 常态 CPU 占用平均 <= 5%。

### 6.2 稳定性

1. 单日运行崩溃率 < 1%。
2. 关键功能失败可恢复（提醒、待办、番茄钟）。

### 6.3 安全与隐私

1. 用户数据默认本地存储。
2. 明确标注网络请求行为（调用模型时）。
3. API Key 本地加密存储。

### 6.4 离线可用（上线硬约束）

1. 无网络状态下，P0 核心功能仍可使用：桌宠常驻、提醒、番茄钟、待办、基础记忆读写。
2. 无网络状态下，对话模块需降级到本地模型或离线提示（可配置）。
3. 网络恢复后，可选择性同步离线期间的数据变更（若启用云能力）。

## 7. 关键指标（MVP验收）

1. D1 留存 >= 35%。
2. D7 留存 >= 15%。
3. 人均日提醒完成次数 >= 2。
4. 番茄钟启动率 >= 25%。
5. 日均主动唤起次数 >= 3。
6. 崩溃率 < 1%。

## 8. 版本计划（PRD视角）

1. 里程碑 M1（第1-2周）：桌宠壳层、对话唤起、设置页基础。
2. 里程碑 M2（第3-4周）：提醒、番茄钟、待办闭环。
3. 里程碑 M3（第5-6周）：记忆与隐私治理、离线能力打磨。
4. 里程碑 M4（第7-8周）：优化、灰度内测、指标埋点验证。

## 9. 需求决策（已确认）

1. 首发平台：仅 Windows。
2. 价值权重：陪伴:效率 = 6:4。
3. 截图问答：保持为 P1，不纳入 v0.2 的 P0 范围。
4. 离线可用：作为上线硬约束。

## 10. 术语说明

1. MVP：最小可行产品，目标是验证核心价值。
2. 轻任务闭环：任务从创建、提醒到完成形成完整流程。
3. 记忆：指用户授权下保存的偏好和习惯数据，不含敏感原文长期存储。
